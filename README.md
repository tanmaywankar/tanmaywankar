###  Key Projects
*  **Grobot Ecosystem:** Architected a 3-tier reactive platform managing synchronized bidirectional data flow between an ESP32 hardware client, Node.js backend, and a real-time Vue.js dashboard using native WebSockets and in-memory DB batching.
*  **CHIP-8 CPU Emulator:** Low-level CPU interpreter built in C++ handling instruction decoding, opcode execution, and timers; compiled to WebAssembly (WASM) running in the browser at 60 FPS.
*  **Grobot Animator:** Web-based visual studio and code generator for microcontroller animation frames paired with an official Arduino C++ physics library.
